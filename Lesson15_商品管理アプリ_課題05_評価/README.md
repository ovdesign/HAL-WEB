## Lesson15 評価課題「商品管理アプリ」

### 到達目標

Lesson1からLesson14までの学習内容を組み合わせ、指定された要件を満たすJavaScriptアプリを自力で完成させられる。

### 課題概要

ECサイトの商品管理画面を想定し、JavaScriptを使用して商品データの登録・一覧表示・削除・検索・件数表示・入力チェックを実装する。

### 必須入力項目

- 商品名
- カテゴリ
- 価格

### 必須機能

1. フォームから商品を登録できる。
2. 商品をオブジェクトとして作成し、配列で管理できる。
3. 登録済みの商品をDOMへ一覧表示できる。
4. 各商品に削除ボタンを設置し、選択した商品を削除できる。
5. 商品名によるキーワード検索ができる。
6. 現在表示中の商品件数を表示できる。
7. 未入力または不正な価格がある場合、商品を登録せずエラーメッセージを表示できる。

### 使用必須技術

- `let` または `const`
- `if`
- 関数
- 配列
- オブジェクト
- `forEach()`
- `filter()`
- `querySelector()`
- `addEventListener()`

### 制作条件

- HTML、CSS、JavaScriptを使用すること。
- jQuery、Bootstrap、Vue、Reactなどの外部ライブラリやフレームワークは使用しないこと。
- 商品データはオブジェクト配列で管理すること。
- 処理内容に応じて関数を分けること。
- ファイルは `index.html`、`style.css`、`script.js` の3ファイルを基本構成とすること。

### データ構造例

```javascript
const products = [
  {
    id: 1,
    name: "ノートPC",
    category: "家電",
    price: 98000
  }
];
```

必須機能の完成後、次の機能追加に挑戦してよい。

- 価格の安い順・高い順への並び替え
